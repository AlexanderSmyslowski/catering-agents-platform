# User Story Inventory Tracker

## Ziel
Alle aus Code und Tests belegbaren Nutzerfunktionen der Catering-Plattform als User Stories in einer einzigen kanonischen Tabelle erfassen.

## Umfang dieser Einheit
- Feature-Inventar aus UI-Routen, Service-Endpunkten, Exporten, Skripten und Tests ableiten.
- Erwartetes Verhalten und Quellbelege je Story festhalten.
- Status-Spalten fuer spaetere Test-, Fehler- und Fix-Loops vorbereiten.

## Nicht in dieser Einheit
- Keine Produktfixes.
- Keine UI-/Service-Umbauten.
- Keine neue Fachlogik.

## Abnahme
- Eine `.xlsx`-Tabelle enthaelt alle inventarisierten Stories mit Statusfeldern.
- Jede Story hat mindestens einen Code- oder Testbeleg.
- Workbook ist exportiert und visuell/strukturell geprueft.
