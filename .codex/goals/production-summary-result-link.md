# Production Summary Result Link

- Ziel: Bei vorhandenem Produktionsartefakt aus der sichtbaren Zusammenfassung direkt zum Ergebnisbereich springen.
- Scope: Backoffice-Workbench-Anker und Tests; keine API-, Schema- oder Planungslogik.
- Beobachtung: Browser-Probe zeigte im ersten Viewport nur Navigation, obwohl Plan und Einkaufsliste vorhanden waren.
- Erfolg: Die Zusammenfassung enthält einen Link zum bestehenden Produktionsarbeitsbereich.
