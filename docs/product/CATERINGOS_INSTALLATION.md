# CateringOS als App verwenden

Öffne [CateringOS](https://catering.the-one.catering/) im gewünschten Browser.

## Mac / Safari

Ab macOS Sonoma 14:
1. CateringOS in Safari öffnen.
2. **Ablage → Zum Dock hinzufügen** wählen und den Namen **CateringOS** bestätigen.
3. CateringOS anschließend über das Dock als eigene Web-App starten.

## iPhone / iPad

1. CateringOS in Safari öffnen.
2. **Teilen** wählen (je nach Safari-Layout zuerst **Mehr**).
3. **Zum Home-Bildschirm** wählen und hinzufügen. Falls angeboten, **Als Web-App öffnen** eingeschaltet lassen.

## Windows / Chrome oder Edge

1. CateringOS öffnen.
2. Die Installationsmöglichkeit in der Adressleiste oder im Browsermenü verwenden, soweit angeboten.
3. CateringOS anschließend über das Startmenü oder die angelegte Verknüpfung starten.

Eine Internetverbindung ist erforderlich. Es gelten dieselben CateringOS-Zugangsdaten.
Safari-Web-Apps können eine erneute Anmeldung verlangen; Anmeldung und Abmeldung
im Browser und in der Web-App können unabhängig voneinander sein.
Updates kommen weiterhin über die bestehende Webanwendung. Eine bereits geöffnete
App nach einem Update neu laden oder schließen und erneut öffnen.

Browserhilfe: [Apple Mac](https://support.apple.com/en-us/104996),
[Apple iPhone](https://support.apple.com/guide/iphone/iphea86e5236/ios),
[Apple iPad](https://support.apple.com/guide/ipad/open-as-web-app-ipad8f1f7a29/ipados).
